# 神煞系统详解

> 八字中的特殊组合，分为吉神和凶煞
> 神煞可作为辅助判断，但不可单凭神煞断命
> 最后更新：2026-04-23

---

## 神煞使用原则

1. **神煞为辅**：不可单凭神煞断命，需结合五行生克
2. **吉凶相对**：吉神未必全吉，凶煞未必全凶
3. **组合论断**：神煞组合可改变性质（如桃花 + 文昌 = 艺术才华）
4. **旺衰为体**：身旺能担煞，身弱怕煞侵
5. **时代变迁**：古代凶煞在现代可能为吉（如驿马主奔波，现代利于出差升迁）

## 吉神

### 天乙贵人

**最吉之神**，主贵人相助、逢凶化吉

**查法**（以日干或年干查地支）：

| 日/年干 | 贵人地支 |
|---------|----------|
| 甲、戊、庚 | 丑、未 |
| 乙、己 | 子、申 |
| 丙、丁 | 亥、酉 |
| 壬、癸 | 巳、卯 |
| 辛 | 午、寅 |

**口诀**：
> 甲戊庚牛羊，乙己鼠猴乡。
> 丙丁猪鸡位，壬癸蛇兔藏。
> 辛马逢寅虎，天乙贵人方。

**作用**：
- 命中有贵人，一生多得帮助
- 逢凶化吉，遇难呈祥
- 利于求官、求职、求财

## 凶煞

### 桃花（咸池）

**主感情、异性缘、艺术**

**查法**（以年支或日支查）：

| 年/日支 | 桃花 |
|---------|------|
| 申子辰 | 酉 |
| 寅午戌 | 卯 |
| 亥卯未 | 子 |
| 巳酉丑 | 午 |

**口诀**：
> 申子辰在酉，寅午戌在卯。
> 亥卯未在子，巳酉丑在午。

**作用**：
- 正面：异性缘好，艺术才华，人缘佳
- 负面：感情纠纷，桃花劫，色情之灾
- 墙内桃花（年支查）：夫妻恩爱
- 墙外桃花（日支查）：易有外遇

| 年/日支 | 驿马 |
|---------|------|
| 申子辰 | 寅 |
| 寅午戌 | 申 |
| 亥卯未 | 巳 |
| 巳酉丑 | 亥 |

**口诀**：
> 申子辰马在寅，寅午戌马在申。
> 亥卯未马在巳，巳酉丑马在亥。

- 负面：奔波劳碌，居无定所
