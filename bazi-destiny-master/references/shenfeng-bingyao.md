## 一、病药论核心

### 张神峰原文（选段）

> 有病方为贵，无伤不是奇。格中如去病，财禄两相随。
> 何以为之病？八字中所有害格局者皆是也。何以为之药？八字中所有去病之神即是也。
> 凡看命，先看月令提纲，看是何格局，再看有何病，再看药在何处。

### 核心思想

八字的结构性缺陷（"病"）恰恰是成格的关键。原局有病，有药可医，才能论贵论富。若八字无病也无药，平庸之命；有病无药，则为困局。

## 二、病药分类

### 常见"病"的类型

| 病的类型 | 表现 | 示例 |
|----------|------|------|
| **格局病** | 格局有破格因素 | 正官格见伤官、财格被比劫夺 |
| **旺衰病** | 身弱财官旺或身旺无依 | 身弱杀重、身旺无制 |
| **调候病** | 寒暖燥湿极端 | 冬生无火、夏生无水 |
| **刑冲病** | 关键宫位受冲刑 | 日支逢冲、月令被冲 |
| **清浊病** | 格局混杂不清 | 官杀混杂、正偏财同透 |
| **五行病** | 某五行过强或缺失 | 土重埋金、木多火塞 |

### 常见"药"的类型

| 药的类型 | 作用 | 示例 |
|----------|------|------|
| **制化药** | 克制或化解病神 | 食神制杀、印化官杀 |
| **通关药** | 化解两行相战 | 金木相战用水通关 |
| **调候药** | 调节寒暖燥湿 | 冬生用火、夏生用水 |
| **配合药** | 搭配用神 | 官格配财配印 |
| **合化药** | 用合化解冲刑 | 子午冲用丑合子 |

## 三、病药论格局成败修正法

> 此为正文件的核心价值：在 geju-chengbai.md 的基础上，用病药论进行二次修正。

### 修正流程

```
月令取格（geju-chengbai.md）
    │
    ├── 识别格局的"病"（本文件）
    │     │
    │     ├── 有病？
    │     │   ├── 有药 ☑ 病去成功 → 格高（上调一级）
    │     │   └── 无药 ✗ → 格破（下调一级，带风险提示）
    │     │
    │     └── 无病？
    │         ├── 有药可用 → 常格（正常判断）
    │         └── 无药可用 → 平庸（下调一级）
    │
    └── 输出"格局成败 + 病药修正"
```

### 修正对照表

| geju-chengbai.md 判断 | 病药修正 | 最终建议 |
|----------------------|----------|---------|
| **格局成** | 有病有药 | **上调**：格局清贵，有波折但可成 |
| **格局成** | 有病无药 | **降级**：格虽成但有隐患，某某年某某运引动时易出事 |
| **格局成** | 无病无药 | **持平**：平稳但无大起色 |
| **格局破** | 有病有药 | **上调可能性**：破中有救，若大运得药则反败为成 |
| **格局破** | 有病无药 | **确认降级**：格破无救，调低事业财富总评 |

## 五、病药的应期：大运与流年

> 病药不只是原局概念，大运和流年是药到位的应期。

### 大运得药

- 原局有病，大运恰好走"药"运 → **十年黄金期**
- 例如：原局伤官克官（病），大运走印运（药）→ 印制约伤官，护官，在此期间事业稳定、贵人有力
- 例如：原局杀重身轻（病），大运走印运（药）→ 印化杀生身，压力变权柄

### 大运添病

- 原局本无此病，大运带来→ **十年需注意期**
- 例如：原局官星清净，大运走伤官运（添病）→ 伤官克官，事业波动、是非多

### 流年获药

- 单年药到 → 该年顺利、有转机
- 例如：原局比劫夺财（病），流年官杀制比劫护财（药）→ 当年得财、被提拔或规避损失

### 流年引病

- 单年病发 → 该年不顺
- 例如：原局有伤官见官的"病"，流年触发正官（引病）→ 该年需防口舌是非

## 八、使用优先级

1. **格局成败**（`geju-chengbai.md` + 《子平真诠》）→ 第一判断
2. **病药修正**（本文件）→ 在上一步基础上做二次修正，决定"上调/下调/持平"
3. **调候修正**（`qiongtong-baojian.md`）→ 在病药基础上再做调候修正
4. **最终输出**：格局 + 病药修正 + 调候修正 → 综合定级

**限制**：
- 病药修正的调级最大幅度为 ±1 级（如"小富"可上调至"中富"，不可跳至"大富"）。
- 若病药修正与调候修正方向相反，以病药修正为准，调候只做备注说明。
- 病药论不单独断命，不替换格局主轴。
