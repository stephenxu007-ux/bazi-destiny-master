# 真太阳时校正原理

> 真太阳时是八字排盘的关键，影响时柱准确性
> 不同地点出生，北京时间相同，但真太阳时不同
> 最后更新：2026-04-23

---

## 核心概念

**真太阳时**：根据太阳实际位置确定的时间，反映真实的时辰。

**北京时间**：以东经120°为基准的标准时间。

**本体系规则**：默认用真太阳时排盘，而非直接用北京时间。若用户明确要求北京时间排盘，必须在报告中注明“未校正真太阳时”。

---

## 一、原理说明

### 1. 地球自转与时间

- 地球每24小时自转一圈（360°）
- 每小时转15°
- 每度对应4分钟

### 2. 北京时间基准

- 北京时间以东经120°为基准
- 并非北京的实际经度（北京约116°）
- 是国际标准时区划分

### 3. 经度与时间差

| 地点 | 经度 | 与120°差 | 时间差 |
|------|------|---------|--------|
| 北京 | 116° | -4° | 比北京时间晚16分钟 |
| 上海 | 121° | +1° | 比北京时间早4分钟 |
| 成都 | 104° | -16° | 比北京时间晚64分钟 |
| 乌鲁木齐 | 87° | -33° | 比北京时间晚132分钟 |
| 哈尔滨 | 126° | +6° | 比北京时间早24分钟 |

## 二、校正顺序与公式

### 0. 先校正大陆夏令时

1986-1991年中国大陆实行夏令时，出生证明或户口登记时间通常是当时钟表时间。若出生时间落在下列区间，先减1小时，还原为标准北京时间，再做真太阳时校正。

| 年份 | 夏令时开始 | 夏令时结束 | 排盘处理 |
|------|------------|------------|----------|
| 1986 | 05-04 02:00 | 09-14 02:00 | 记录时间减1小时 |
| 1987 | 04-12 02:00 | 09-13 02:00 | 记录时间减1小时 |
| 1988 | 04-17 02:00 | 09-11 02:00 | 记录时间减1小时 |
| 1989 | 04-16 02:00 | 09-17 02:00 | 记录时间减1小时 |
| 1990 | 04-15 02:00 | 09-16 02:00 | 记录时间减1小时 |
| 1991 | 04-14 02:00 | 09-15 02:00 | 记录时间减1小时 |

报告必须写明：原始记录时间、夏令时校正后的标准北京时间、真太阳时。

资料来源：北京日报关于我国1986-1991年实行夏时制的历史回顾；timeanddate.com逐年时区变更记录。

### 1. 基本公式

```
真太阳时 = 标准北京时间 + (当地经度 - 120°) × 4分钟

例：成都出生，北京时间14:00
真太阳时 = 14:00 + (104 - 120) × 4
         = 14:00 + (-16) × 4
         = 14:00 - 64分钟
         = 12:56
```

### 2. 简化口诀

> 东经早，西经晚，每度差四分。
> 先算经度差，再乘四分钟。

### 3. 注意事项

- 东经大于120°：真太阳时比北京时间早
- 东经小于120°：真太阳时比北京时间晚
- 结果可能跨日（早于0点或晚于24点）
- 临界时辰需复核均时差；本脚本默认只做经度校正，不自动加入均时差

### 4. 晚子时换日

本体系采用“晚子时换日”：

- 23:00-23:59出生：仍为子时，但日柱按次日干支排，时干也随次日日干起。
- 00:00-00:59出生：自然属于当天子时。
- 若夏令时、真太阳时校正后落入23:00-23:59，以校正后的真太阳时为准换日。

## 五、实例计算

### 1. 实例一：成都午时判断

```
出生信息：
- 地点：成都（104°E）
- 北京时间：13:30

计算：
- 时间差 = (104 - 120) × 4 = -64分钟
- 真太阳时 = 13:30 - 64分钟 = 12:26
- 时辰：午时（11:00-13:00）

结论：北京时间13:30在成都实际是午时
```

### 2. 实例二：哈尔滨子时判断

```
出生信息：
- 地点：哈尔滨（126°E）
- 北京时间：00:30

计算：
- 时间差 = (126 - 120) × 4 = +24分钟
- 真太阳时 = 00:30 + 24分钟 = 00:54
- 时辰：子时（23:00-01:00）

结论：北京时间00:30在哈尔滨仍是子时
```

### 3. 实例三：乌鲁木齐跨日判断

```
出生信息：
- 地点：乌鲁木齐（87°E）
- 北京时间：02:00

计算：
- 时间差 = (87 - 120) × 4 = -132分钟
- 真太阳时 = 02:00 - 132分钟 = 23:48（前一天）
- 时辰：子时（23:00-01:00）

结论：北京时间02:00在乌鲁木齐实际是前一天的子时
```

## 六、均时差（进阶）

### 1. 什么是均时差

**均时差**：由于地球公转轨道椭圆和自转轴倾斜，真太阳时与平太阳时之间存在差异。

**最大值**：约±16分钟

### 2. 均时差表（近似）

| 月份 | 均时差（分钟） |
|------|--------------|
| 1月 | -3 ~ +3 |
| 2月 | -14 ~ +14 |
| 3月 | -12 ~ +4 |
| 4月 | -4 ~ +0 |
| 5月 | +0 ~ +3 |
| 6月 | +0 ~ -2 |
| 7月 | -6 ~ -4 |
| 8月 | -6 ~ +0 |
| 9月 | +0 ~ +10 |
| 10月 | +10 ~ +16 |
| 11月 | +16 ~ +10 |
| 12月 | +10 ~ +3 |

### 3. 完整公式（精确）

```
真太阳时 = 北京时间 + 经度校正 + 均时差

经度校正 = (当地经度 - 120) × 4分钟
均时差 = 查表或天文算法计算
```

## 七、排盘工具实现

### 1. 代码逻辑

```python
def calc_true_solar_time(hour, minute, longitude):
    # 北京时间基准经度120°
    beijing_lon = 120.0
    
    # 经度校正（每度4分钟）
    time_diff = (longitude - beijing_lon) * 4
    
    # 均时差（简化为0，实际需天文算法）
    eq_time = 0
    
    # 真太阳时
    total_minutes = hour * 60 + minute + time_diff
    
    # 处理跨日
    if total_minutes < 0:
        total_minutes += 1440  # 加24小时
    elif total_minutes >= 1440:
        total_minutes -= 1440  # 减24小时
    
    true_hour = total_minutes // 60
    true_minute = total_minutes % 60
    
    return true_hour, true_minute
```

## 八、使用原则

1. **默认校正**：本体系默认用真太阳时；若用户指定北京时间排盘，需注明未校正
2. **先还原钟表时间**：1986-1991大陆夏令时区间，先减1小时
3. **时辰为准**：以校正后的真太阳时定时辰
4. **晚子换日**：23:00-23:59按次日干支排
5. **跨日注意**：西部地区可能跨日前一天
6. **工具优先**：使用排盘脚本，并对临界时辰人工复核

## 九、常见错误

| 错误 | 正确做法 |
|------|---------|
| 直接用北京时间排盘 | 先校正为真太阳时 |
| 忽略经度差异 | 根据出生地经度校正 |
| 忽略跨日情况 | 西部地区注意可能跨日 |
| 只用城市名 | 需知道城市经度 |
