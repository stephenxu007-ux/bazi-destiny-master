# 生旺墓库与家境资产断法

> 基于子平法、十二长生、财官印格局成败，用于修正“见财即富、见库即有资产”的粗断。
> 最后更新：2026-05-21

---

## 一、核心原则

家境、父辈资产、个人财富不能只看一个财星。必须按以下顺序判断：

```
六亲星 → 六亲宫 → 月令旺衰 → 十二长生 → 墓库开合 → 格局喜忌 → 大运承接 → 流年应事
```

经典口径：

- 《子平真诠》重月令格局，财格要身财两停，财多身弱不任财。
- 《滴天髓》重体用清浊，财官印食要有情，浊杂无情则降层。
- 《三命通会》以年柱看祖上、月柱看父母兄弟、日支看配偶、时柱看子女，宫星同参。
- 十二长生用于判断五行有气无气，不能只看“天干透出”。

---

## 二、十二长生用于断层级

### 1. 星的状态

| 状态 | 力量 | 用法 |
|------|------|------|
| 长生、冠带 | 有生机 | 有发展、有人帮、可培养 |
| 临官、帝旺 | 旺 | 有力、能主事、容易外显 |
| 衰、病、死、绝 | 弱 | 有名无实、难承担、容易辛苦 |
| 墓 | 收藏 | 有库、有积累象，但需冲开或运引；也可能是被困、迟滞 |
| 胎、养 | 未成 | 有苗头但早年不显 |

### 2. 判断家境时怎么用

| 情况 | 结论口径 |
|------|----------|
| 财星在年月且临官帝旺，为喜用，父母宫不破 | 家境较好，父辈资源可见 |
| 财星在年月但为忌，或财生杀攻身 | 家里重钱、压力重、父辈辛苦，不等于富 |
| 财星入库且库得护 | 有积累、房产、资产沉淀倾向 |
| 财星入库但库被冲破、比劫夺财 | 有资产议题但反复，可能体现为债务、房贷、分家、资金压力 |
| 财星透但无根或落死绝 | 有赚钱想法/财务目标，但现实资产有限 |
| 年月财旺但日主弱不任财 | 父辈或家庭财务压力容易转嫁给命主 |

## 三、墓库不是一定有钱

辰戌丑未为四库，也为杂气。见库要分：

| 类型 | 判断 |
|------|------|
| 财库 | 有资产、房产、资金池、储蓄、项目款的象 |
| 印库 | 学历、文书、房屋、母系、贵人、保护资源 |
| 官杀库 | 规则、职位、压力、病灾、权责收藏 |
| 食伤库 | 技艺、产品、子女、生养、输出能力收藏 |

### 开库与破库

| 情况 | 断法 |
|------|------|
| 库被合 | 多为合住、牵绊、资源被绑定，未必能用 |
| 库被冲 | 资源被打开，也可能动荡、破财、搬家、分家 |
| 库为喜用被冲开 | 可能应置业、得财、项目落地 |
| 库为忌神被冲开 | 可能应债务、破财、官非、健康压力 |
| 库多而日主弱 | 责任、债务、家庭资产压力大于享受 |

**硬规则**：不能写“有辰戌丑未就是有房有钱”。必须判断库中所藏十神、喜忌、冲合、日主能否承载。

## 四、父辈条件的三层断法

### 第一层：父辈财务信息

出现以下任一，可断“父辈/家里财务议题明显”：

- 年月见财星或财库。
- 财星透出但喜忌未明。
- 财星合入年月或父母宫。
- 财星被冲合刑害，主家中钱财事件多。

这层不能直接断富，只能断：重钱、现实、辛苦求财、房产/债务/经营议题。

### 第二层：家境有底子

需要同时满足较多条件：

- 年月财、官、印至少两类配合，不孤不偏。
- 财星为喜用，或虽为忌但有印比承接。
- 父母宫不被严重冲破，不落严重空亡。
- 财库得护，或早年大运助年月父母宫。

可断：小康、有房产、有稳定资源、父母能托举一部分。

### 第三层：父辈资产多/办厂经营

需要看到体系，不是单个财星：

- 年月柱有财官印食成链条，例如食伤生财、财生官、官印相生。
- 财星有根有库，库不被严重破坏。
- 月令支持经营之气，或财官在年月得令得地。
- 早年大运帮年月财官印，父辈事业容易在命主早年显现。
- 命局有明显“生产经营、管理、厂房设备、土地资产”的金土火木流转。

可断：父辈经商、办厂、资产较多、家庭经营盘子大。

## 五、个人财富与父辈家境要分开

| 项目 | 看法 |
|------|------|
| 父辈家境 | 年柱、月柱、父母星、财印库、早年大运 |
| 命主能否承接 | 日主强弱、财为喜忌、印比是否帮身、格局是否成 |
| 命主财富 | 财星位置、食伤生财、身财能否两停、中年大运 |
| 钱财压力 | 财旺为忌、财生杀、身弱财重、库冲破、比劫夺财 |

例：财星旺在年月，父辈可能重财或有赚钱能力；但若命主身弱、财杀压身、印比不足，现实常表现为家庭财务压力、房贷、父母辛苦、资源难承接，而不是轻松继承。

## 六、案例校正规则

当用户反馈家境事实：

1. 先回到原局，区分“财象明显”还是“资产厚”。
2. 若原断把财星直接解释成家底厚，要修正为“财务议题明显”。
3. 找年月财官印是否成体系；若不成体系，不再断父辈资产多。
4. 看早年大运是否帮年月父母宫；不帮者，家里有财象也可能只是辛苦求财。
5. 后续同类命例必须用这套层级，不得用反馈去圆话。

## 七、报告固定写法

家境资产章节必须按以下结构：

```markdown
### 家境资产层级

| 项目 | 判断 |
|------|------|
| 财星/财库 | 有无、位置、是否得令得地 |
| 年月父母宫 | 是否成体系，是否冲破 |
| 十二长生 | 财星、父母星、日主在年月状态 |
| 喜忌承接 | 财为用还是为忌，日主能否担财 |
| 早年大运 | 是否助父母宫和财官印 |
| 结论 | 财务议题明显/家境普通/小康有底/资产较多 |

依据：子平六亲法、十二长生、财格身财两停、宫星同参。
```
