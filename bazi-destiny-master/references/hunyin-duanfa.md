## 一、夫妻宫判断

### 1. 夫妻宫基本概念

夫妻宫即日支，代表配偶的位置和婚姻状况。

**四柱分宫**：
| 柱位 | 宫位 | 代表年龄段 |
|------|------|-----------|
| 年柱 | 祖上/父母宫 | 1-16岁 |
| 月柱 | 父母/兄弟宫 | 17-32岁 |
| 日支 | 夫妻宫 | 33-48岁 |
| 时柱 | 子女宫 | 49岁以后 |

### 2. 日支十神与婚姻

| 日支十神 | 男命含义 | 女命含义 | 婚姻特点 |
|---------|---------|---------|---------|
| 正财 | 妻贤惠，婚姻稳定 | 配偶稳重，善理财 | 婚姻和睦，感情稳定 |
| 偏财 | 妻性活泛，或有外缘 | 配偶风趣，有偏财运 | 婚姻有变数，需注意 |
| 正官 | 妻端庄，有约束力 | 夫正派，有社会地位 | 婚姻稳定，配偶有成 |
| 七杀 | 妻性强，婚姻有波折 | 夫霸道或能力强 | 婚姻有压力，需磨合 |
| 正印 | 妻慈祥，得长辈助 | 配偶仁慈，有学历 | 婚姻和谐，有贵人助 |
| 偏印 | 妻孤僻，沟通不畅 | 配偶敏感，多思虑 | 婚姻有隔阂，需沟通 |
| 比肩 | 妻同心，但也竞争 | 配偶同辈缘分深 | 婚姻平等，但也争执 |
| 劫财 | 婚姻多波折，克妻 | 婚姻不顺，易有争执 | 婚姻风险大，需谨慎 |
| 食神 | 妻温顺，善持家 | 配偶温和，有口福 | 婚姻和睦，生活美满 |
| 伤官 | 妻聪慧但任性 | 克夫，婚姻不顺 | 婚姻有变数，需注意 |

### 3. 日支合冲刑害

**日支逢合（吉）**：
- 六合：子丑合、寅亥合、卯戌合、辰酉合、巳申合、午未合
- 三合：申子辰、亥卯未、寅午戌、巳酉丑
- 合多者，婚姻稳定，感情和睦

**日支逢冲（凶）**：
| 的类型 | 婚姻影响 |
|---------|---------|
| 子午冲 | 情感波动大，聚少离多 |
| 丑未冲 | 家庭纷争，婆媳矛盾 |
| 寅申冲 | 异地分居，贵人变动 |
| 卯酉冲 | 桃花纠葛，感情波折 |
辰戌冲 | 矛盾冲突，根基动摇 |
巳亥冲 | 聚少离多，事业变动 |

**日支逢刑**：
- 寅巳申三刑：婚姻有折磨
- 丑戌未三刑：家庭纷争
- 子卯相刑：感情不顺
- 自刑：自我纠结，影响婚姻

**日支逢害**：
- 子未害：婚姻有小人干扰
- 丑午害：家庭不和谐
- 寅巳害：贵人变小人
- 卯辰害：感情有隔阂
- 申亥害：异地分居
- 酉戌害：矛盾冲突

## 二、财官星断婚姻

### 1. 男命以财星为妻

**财星基本判断**：
| 财星状态 | 婚姻含义 |
|---------|---------|
| 正财一位 | 婚姻专一，妻子贤惠 |
| 正财多位 | 感情复杂，有异性缘 |
| 偏财一位 | 感情有变数，或晚婚 |
| 偏财多位 | 外缘多，感情复杂 |
| 正偏财混杂 | 感情复杂，易有婚外情 |
| 财星透干 | 妻子外向，社交能力强 |
| 财星藏支 | 妻子内敛，持家有道 |
| 财星入墓 | 妻缘浅薄，或妻子身体弱 |
| 财星逢合 | 妻子有外遇或感情纠葛 |
| 财星遭克 | 克妻或离婚风险 |

**财星与日主关系**：
| 关系 | 婚姻含义 |
|------|---------|
| 财为喜用，有根气 | 婚姻美满，妻子得力有助 |
| 财为喜用，无根气 | 婚姻尚可，妻子助力有限 |
| 财为忌神，有根气 | 婚姻不利，妻子累赘或拖累 |
| 财为忌神，无根气 | 婚姻尚可，妻子影响有限 |
| 身财两停 | 婚姻美满，富贵双全 |
| 财多身弱 | 婚姻压力大，难以任财 |

**男命婚姻断语**：
- 正财一位得位，妻贤子孝
- 比劫多见，克妻再娶
- 偏财透出，外情难免
- 财星入墓，妻缘浅薄
- 财星逢冲，婚姻多变
- 日支坐财，妻得位有助

### 2. 女命以官星为夫

**官星基本判断**：
| 官星状态 | 婚姻含义 |
|---------|---------|
| 正官一位 | 婚姻稳定，夫正派有成 |
| 正官多位 | 异性缘好，感情复杂 |
| 七杀一位 | 婚姻有压力，夫能力强 |
| 七杀多位 | 感情复杂，婚姻多波折 |
| 官杀混杂 | 感情复杂，婚姻不顺 |
| 官星透干 | 丈夫外向，有社会地位 |
| 官星藏支 | 丈夫内敛，为人低调 |
| 官星入墓 | 夫缘浅薄，或丈夫身体弱 |
| 官星逢合 | 丈夫有外遇或感情纠葛 |
| 官星遭克 | 克夫或离婚风险 |

**官星与日主关系**：
| 关系 | 婚姻含义 |
|------|---------|
| 官为喜用，有根气 | 婚姻美满，丈夫得力有成 |
| 官为喜用，无根气 | 婚姻尚可，丈夫成就有限 |
| 官为忌神，有根气 | 婚姻不利，丈夫压力大或伤害 |
| 官为忌神，无根气 | 婚姻尚可，丈夫影响有限 |
| 身官两停 | 婚姻美满，夫荣妻贵 |
| 审多身弱 | 婚姻压力大，难以任官 |

**女命婚姻断语**：
- 正官一位得位，夫荣子贵
- 伤官见官，婚姻多波折
- 官杀混杂，感情复杂
- 官星入墓，夫缘浅薄
- 官星逢冲，婚姻多变
- 日支坐官，夫得位有成

## 三、婚姻时机判断

### 1. 结婚时间判断原则

**大运流年法**：
| 条件 | 判断 |
|------|------|
| 男命大运走财运 | 婚期到来 |
| 女命大运走官运 | 婚期到来 |
| 流年引动夫妻宫（合冲） | 婚姻有变动 |
| 流年透出财官星 | 婚期将至 |

**桃花星法**：
- 桃花星出现（子午卯酉）：异性缘好
- 红鸾星：主婚姻喜庆
- 天喜星：主婚姻顺利

**红鸾天喜查法**：
| 年支 | 红鸾 | 天喜 |
|------|------|------|
| 子 | 卯 | 酉 |
| 丑 | 寅 | 申 |
|寅 | 丑 | 未 |
| 卯 | 子 | 午 |
|辰 | 亥 | 巳 |
|巳 | 戌 |辰 |
|午 |酉 | 卯 |
| 未 | 申 | 寅 |
|申 | 未 | 丑 |
|酉 |午 | 子 |
|戌 |巳 |亥 |
|亥 |辰 | 戌 |

**合局法**：
- 天地合：流年与日柱天干地支皆合，婚期到
- 三合六合：流年与日支或财官星相合
- 日支逢合：婚姻有变动（结婚或离婚）

### 2. 早婚晚婚判断

**早婚信息**：
- 日支逢合不逢冲
- 财官星为喜用且早现
- 红鸾天喜早现
- 桃花星适度
- 早运走财官运

**晚婚信息**：
- 日支逢冲
- 财官星为忌神
- 比劫重重（男命）
- 伤官重重（女命）
- 财官星入墓
- 夫妻宫坐孤寡星
- 晚运才走财官运

## 四、婚姻质量判断

### 1. 婚姻美满信息

| 条件 | 说明 |
|------|------|
| 日支为喜用神 | 配偶得力有助 |
| 财官星为喜用且得力 | 配偶有成有助 |
| 日支逢合不逢冲 | 婚姻稳定和睦 |
| 桃花星适度 | 异性缘好但不泛滥 |
| 无伤官见官（女命） | 不克夫 |
| 无比劫夺财（男命） | 不克妻 |
| 红鸾天喜入命 | 婚姻喜庆 |

### 2. 婚姻不顺信息

| 条件 | 说明 |
|------|------|
| 日支逢冲 | 婚姻不稳定 |
| 财官星遭克 | 配偶有灾或离婚 |
| 比劫重重（男命） | 克妻信息 |
| 伤官重重（女命） | 克夫信息 |
| 夫妻宫坐忌神 | 配偶不利 |
| 财官星混杂 | 感情复杂 |
| 桃花过旺 | 异性缘泛滥 |

### 3. 离婚风险信息

| 条件 | 风险程度 |
|------|---------|
| 日支严重逢冲 | 高风险 |
| 财官星被克严重 | 高风险 |
| 桃花过旺+日支逢冲 | 高风险 |
| 财官星逢合有外遇 | 中风险 |
| 比劫夺财+财星无护 | 中风险（男命） |
| 伤官见官+官星无护 | 中风险（女命） |
| 大运流年引发凶象 | 需看具体组合 |

### 4. 配偶能力判断

| 条件 | 说明 |
|------|------|
| 财官星旺相有根 | 配偶能力强有成 |
| 财官星休囚无根 | 配偶能力一般 |
| 财官星得位（日支） | 配偶助力大 |
| 财官星失位 | 配偶助力小 |
| 财官星逢贵人 | 配偶有贵人运 |
| 财官星逢空亡 | 配偶缘浅或能力难发挥 |

## 五、梁湘润体系特色

### 1. 格局论婚姻

梁湘润强调从格局角度分析婚姻：

| 格局类型 | 婚姻特点 |
|---------|---------|
| 格局清正者 | 婚姻多顺 |
| 格局混杂者 | 婚姻多波折 |
| 用神有力者 | 配偶得力 |
| 用神无力者 | 配偶难助 |
| 正格成格者 | 婚姻稳定 |
| 外格成格者 | 婚姻特殊 |

### 2. 调候论婚姻

注重调候对婚姻的影响：

| 调候状态 | 婚姻影响 |
|---------|---------|
| 寒暖燥湿调和 | 婚姻和谐 |
| 调候用神得力 | 婚姻顺利 |
| 调候失衡 | 婚姻不和 |
| 过寒需火 | 婚姻需温暖 |
| 过热需水 | 婚姻需冷静 |

### 3. 神煞论婚姻

重视神煞对婚姻的影响：

| 神煞 | 婚姻影响 |
|------|---------|

## 六、综合判断要领

### 判断步骤

1. **先看日支夫妻宫**
   - 日支十神是什么
   - 日支合冲刑害情况
   - 日支喜忌判断

2. **再看财官星**
   - 财官星位置和状态
   - 财官星喜忌判断
   - 财官星遭克情况

3. **结合大运流年**
   - 当前大运是什么
   - 流年引动情况
   - 婚姻时机判断

4. **综合各方面判断**
   - 婚姻质量判断
   - 配偶情况判断
   - 婚姻变动时机

### 注意事项

1. **不可单看一因素断婚姻**：需综合全局
2. **需综合全局分析**：格局、调候、神煞同参
3. **注意男女命的区别**：男看财，女看官
4. **结合大运流年动态分析**：婚姻时机很重要
5. **时代变迁影响**：现代婚姻观念与传统不同
