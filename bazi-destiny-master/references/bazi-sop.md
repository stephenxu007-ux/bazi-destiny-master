# 八字排盘分析标准SOP

> 基于梁湘润子平八字体系，所有判断必须有依据来源
> 最后更新：2026-01-22
> 核心要求：详细、完整、有依据
> 关键原则：命局是车，大运是路，流年是天气。三方联动才是真断法。

---

## 一、任务流程

```
阳历记录时间 → 夏令时/真太阳时/晚子时校正 → 推算八字 → 规则选择器定优先级 → 格局主轴 → 刑冲合害原局 → 用神层级 → 病药修正（格局成败±1级调校） → 命主本人 → 六亲家庭与资产细断 → 子女缘/生育/性别倾向 → 完整大运排盘 → 20-60岁逐年流年运转（每年有吉凶） → 盲派口诀交叉校验（生男生女、发财破财、灾祸信号方向一致性确认） → 买房买车/婚育/灾祸/升迁年份回看与预测 → 断语（有依据、有反证）
```

## ⚙️ 技术实现：Codex 输出规则

完整报告优先直接生成一个 `.md` 文件。若报告很长，需要分段编辑时，必须仍保持“固定报告骨架”顺序，不得因分段遗漏子女专题或逐年吉凶表。

**关键规则**：
1. 手工编辑技能或报告文件时，优先使用 `apply_patch`。
2. 输出后必须验证：文件存在、行数合理、首尾章节完整、子女专题存在、20-60岁逐年表含吉凶列。
3. 不得保留旧版工具名、临时拼接说明或与当前 Codex 环境不符的操作。
4. 下断语前必须先用 `liang-xiangrun-rule-selector.md` 判定本章规则优先级；关键断语要写“依据 + 限制”，不能只有口诀式结论。

**分段建议**：
- Part 1：排盘校验 + 起运推导 + 四柱结构
- Part 2：格局判断 + 刑冲合害 + 命主本人
- Part 3：六亲家庭 + 子女专题（含偏男/偏女、生育难易、应期）
- Part 4：事业财运 + 大运总览
- Part 5：20-40岁逐年流年（每年吉凶）
- Part 6：41-60岁逐年流年（每年吉凶）
- Part 7：事项年份汇总 + 总断 + 复核清单

## 三、报告结构（必须完整输出）

### 固定报告骨架（不得走样）

完整 `.md` 报告必须按以下顺序输出；章节名可以微调，但内容不得省略：

1. 排盘校验：出生记录时间、夏令时、真太阳时、晚子时、地点、性别、四柱。
2. 起运推导：年干阴阳、男女顺逆、取节气、起运年龄、第一步大运。
3. 四柱结构：天干地支、十神、藏干、纳音或宫位。
4. 格局判断：取格、成格/破格、用神救应、依据。
5. 刑冲合害：原局内部所有关键刑冲合害，并落到宫位。
6. 命主本人：性格脾气、能力结构、短板、事业适配、财务习惯。
7. 六亲家庭：祖上、父亲、母亲、兄弟、配偶、家境资产；家境必须用生旺墓库层级表。
8. 子女专题：子女星、时柱、子女缘厚薄、生育难易、偏男/偏女主倾向、子女性格、应期年份、依据和限制。
9. 事业财运：行业、赚钱方式、财富层次、风险。
10. 大运总览：至少8步，必须有吉凶和与原局作用。
11. 20-60岁逐年流年：按大运分组，每年必须有吉凶标记和现实应事。
12. 事项年份汇总：房车、婚恋、子女、升迁、破财/健康风险，过去和未来分列。
13. 总断：一句主轴、优势、风险、关键好运与风险年。

### 规则选择与断语出处（必须执行）

每个完整报告必须在格局判断之前增加一段“规则选择说明”，内容包括：

| 判断项目 | 本案优先规则 | 辅助规则 | 不采用/降级规则 | 原因 |
|----------|--------------|----------|------------------|------|
| 命局主轴 | 月令格局/五行缺一/调候等 | 刑冲合害、天透地藏 | 例：神煞单断降级 | 说明命局条件 |
| 家境父母 | 年月宫+父母星 | 生旺墓库、早年大运 | 例：财旺直接断富降级 | 说明喜忌承接 |
| 事业财运 | 格局+财官食伤 | 身财两停、财库开合 | 例：只看财星数量降级 | 说明能否担财 |
| 配偶子女 | 六亲星+宫位 | 生旺墓绝、岁运触发 | 例：只看时柱降级 | 说明冲合刑害 |
| 格局层次 | 月令格局 | 病药修正 | 例：病药直接替代格局降级 | 说明病、药、药是否有根 |
| 应事校验 | 子平主断 | 盲派口诀交叉验证 | 例：盲派口诀推翻主断降级 | 标注同向/反向和置信度变化 |

关键断语固定写法：

```markdown
依据：X规则（出处体系）+ X星在X宫的旺衰/生旺墓绝 + X大运流年触发。
限制：若X条件不成立，结论降级为X；若只见X而无Y，不可直接断为X。
```

禁止把单一因素直接推成结论：

- 财星旺 ≠ 一定有钱或家境富。
- 官杀旺 ≠ 一定有职位。
- 时柱好 ≠ 一定子女顺。
- 财库见年 ≠ 一定祖上资产多。

## 四、计算规则

### 1. 年柱
- 以立春为界（约2月4日）
- 立春前用上一年干支

### 2. 月柱
- 以节气为界
- 五虎遁口诀：
  - 甲己之年丙作首
  - 乙庚之年戊为头
  - 丙辛之年庚寅上
  - 丁壬壬寅顺水流
  - 戊癸之年甲寅求

### 3. 日柱
- 万年历查询
- 公式计算验证

### 4. 时柱
- 五鼠遁口诀：
  - 甲己还加甲
  - 乙庚丙作初
  - 丙辛从戊起
  - 丁壬庚子居
  - 戊癸起壬子

### 5. 大运
- 阳年男命、阴年女命：顺排
- 阴年男命、阳年女命：逆排
- 3天 = 1岁，1天 = 4个月，1时辰 = 10天

### 6. 流年
- 当前年份干支
- 完整报告必须列20-60岁逐年流年，并按每一步大运分组
- 每年固定列出：年份、年龄、大运、流年、十神/岁运作用、与原局作用、与大运作用、现实应事、吉凶、断语依据
- 不得只列最近10年；用户只问近期时，也要先说明完整运势底色，再聚焦近期

## 附录：梁湘润七大实战法则

### 法则一：五行缺一优先论
**原文**：看八字第一优先是否是"五行缺一"，所缺的那一个五行，优先看是否是"财、官"（妻、夫）以及是否是调候用神。

### 法则二：财官引月令
**原文**：五行若全，优先引"财、官"于月支，以查（夫、妻）星之旺、绝。

### 法则三：刑冲合害先看
**原文**：四柱有无明显之双冲、三刑、全阳、全阴。随即以刑冲六亲字面，与格局、调候等直接关联。

### 法则四：调候为急
**原文**：喜忌问题，一定要确定八字之形态。调候用神：喜忌为第一，依《栏江网》。

### 法则五：格局用神分明
**原文**：格局用神：财喜官，枭忌刃……依《子平真诠》。

### 法则六：天透地藏
**原文**：天干有某一个十神，而地支藏干也有这一十神，称为"天透地藏"，力量最大。

### 法则七：根气轻重制
**原文**：七杀格宜用食神制，设若七杀有根，食神无根，也难论制之有益。反之亦然。
