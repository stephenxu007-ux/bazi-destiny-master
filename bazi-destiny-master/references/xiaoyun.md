# 小运法详解

> 小运是每年运势的细分，与大运流年配合使用，形成三层运势叠加
> 基于梁湘润《子平八字》及传统命理小运理论
> 最后更新：2026-04-23

---

## 核心概念

**小运**：一岁一运，每年换一个，代表当年运势的细微变化。

**三层运势叠加**：
```
大运（十年）→ 主导该阶段的大环境
流年（一年）→ 当年的触发器
小运（一岁）→ 当年的细微调节
```

**从时柱开始推算**：
- **顺排**：从时柱开始，按六十甲子顺序顺推
- **逆排**：从时柱开始，按六十甲子顺序逆推

## 二、小运作用层次

### 1. 三层运势关系

```
流年（当年触发）→ 最活跃，触发具体事件
小运（当年调节）→ 次活跃，调节流年力量
大运（十年环境）→ 稳定，决定该阶段基调
原局（先天体质）→ 最稳定，决定命运层次
```

### 2. 小运与流年的配合

| 配合类型 | 吉凶判断 | 应事 |
|---------|---------|------|
| 流年吉 + 小运吉 | 大吉 | 事半功倍 |
| 流年吉 + 小运凶 | 吉中有凶 | 好事有阻力 |
| 流年凶 + 小运吉 | 凶中有吉 | 坏事有转机 |
| 流年凶 + 小运凶 | 大凶 | 灾祸加重 |

### 3. 小运与大运的配合

| 配合类型 | 吉凶判断 | 应事 |
|---------|---------|------|
| 大运吉 + 小运吉 | 大吉 | 该年特别顺利 |
| 大运吉 + 小运凶 | 吉中有阻 | 该年有小波折 |
| 大运凶 + 小运吉 | 凶中有救 | 该年有缓解 |
| 大运凶 + 小运凶 | 大凶 | 该年灾祸加重 |

## 三、小运与命局的作用

### 1. 小运天干作用

**小运天干与原局天干**：
- 小运天干透出某十神 → 引动该十神事项
- 小运天干合原局天干 → 合化或合绊
- 小运天干冲原局天干 → 天克，变动

### 2. 小运地支作用

**小运地支与原局地支**：
- 小运地支冲原局地支 → 引动该宫位
- 小运地支合原局地支 → 合化或合绊
- 小运地支刑原局地支 → 是非疾病
- 小运地支害原局地支 → 小人不和

### 3. 小运与用神的关系

| 小运类型 | 吉凶判断 | 应事 |
|---------|---------|------|
| 小运是用神 | 吉 | 该年顺利 |
| 小运是喜神 | 吉 | 该年平稳 |
| 小运是忌神 | 凶 | 该年不顺 |
| 小运冲用神 | 大凶 | 该年灾祸 |
| 小运合用神 | 平/凶 | 用神被绊 |
| 小运制忌神 | 吉 | 忌神受制 |

## 四、小运实战断法

### 1. 小运配合流年断事

**公式**：
```
流年干支 + 小运干支 + 原局四柱
→ 找出所有刑冲合会
→ 确定哪个十神被引动
→ 判断三层叠加的吉凶
```

### 2. 小运特殊组合

| 小运合流年 | 该年合作顺利，人和事和 |
| 小运冲日支 | 该年配偶宫动，感情变动 |

## 五、梁湘润小运法则

### 1. 小运与流年并临

当小运与流年干支相同：
- 力量加倍
- 吉者更吉，凶者更凶
- 需特别注意该年

### 2. 小运补救大运

当大运为忌神运，但小运为用神：
- 小运可缓解大运的凶性
- 该年有转机，不至于太差

### 3. 小运加剧大运

当大运为忌神运，小运也为忌神：
- 小运加剧大运的凶性
- 该年灾祸加重，需特别注意

## 六、小运使用原则

### 1. 小运为辅

**原则**：小运是辅助工具，不可单凭小运断命

**优先级**：
```
1. 原局 → 基础
2. 大运 → 主导
3. 流年 → 触发
4. 小运 → 调节
```

### 2. 小运适用范围

**适用**：
- 配合大运流年，判断该年细微变化
- 大运交接年，小运可提前预兆
- 流年与原局无明显作用时，小运可提供线索

**不适用**：
- 单凭小运断命（力量太弱）
- 大运流年已有明确结论时，小运仅作参考

### 3. 小运与年龄段

| 年龄段 | 小运关注度 |
|--------|-----------|
| 少年（1-16岁） | 小运对学业身体有影响 |
| 青年（17-30岁） | 小运对恋爱婚姻有影响 |
| 中年（31-50岁） | 小运对事业财运有影响 |
| 老年（61+岁） | 小运对健康有影响 |

## 七、小运计算代码

```python
def calc_xiaoyun(shizhu_gan, shizhu_zhi, year_gan, gender, age):
    """计算小运"""
    # 判断顺逆
    yang_year = year_gan in ['甲', '丙', '戊', '庚', '壬']
    if yang_year and gender == '男':
        direction = '顺'
    elif not yang_year and gender == '女':
        direction = '顺'
    else:
        direction = '逆'
    
    # 六十甲子
    jiazi = ['甲子', '乙丑', '丙寅', '丁卯', '戊辰', '己巳', 
             '庚午', '辛未', '壬申', '癸酉', '甲戌', '乙亥',
             '丙子', '丁丑', '戊寅', '己卯', '庚辰', '辛巳',
             '壬午', '癸未', '甲申', '乙酉', '丙戌', '丁亥',
             '戊子', '己丑', '庚寅', '辛卯', '壬辰', '癸巳',
             '甲午', '乙未', '丙申', '丁酉', '戊戌', '己亥',
             '庚子', '辛丑', '壬寅', '癸卯', '甲辰', '乙巳',
             '丙午', '丁未', '戊申', '己酉', '庚戌', '辛亥',
             '壬子', '癸丑', '甲寅', '乙卯', '丙辰', '丁巳',
             '戊午', '己未', '庚申', '辛酉', '壬戌', '癸亥']
    
    # 时柱位置
    shizhu = shizhu_gan + shizhu_zhi
    start_idx = jiazi.index(shizhu)
    
    # 推算小运
    if direction == '顺':
        xiaoyun_idx = (start_idx + age - 1) % 60
    else:
        xiaoyun_idx = (start_idx - age + 1) % 60
    
    return jiazi[xiaoyun_idx]
```

## 八、小运总结

1. **小运是辅助**：配合大运流年使用，不可单独断命
2. **一岁一运**：每年换一个小运，从时柱开始
3. **顺逆规则**：阳男阴女顺，阴男阳女逆
4. **三层叠加**：大运 + 流年 + 小运 = 综合判断
5. **力量递减**：流年 > 小运 > 大运对原局的作用
