# 穷通宝鉴调候用神表

> 《穷通宝鉴》（原名《栏江网》）是清代余春台所著的调候用神专著
> 调候为急，寒暖燥湿是第一优先
> 最后更新：2026-04-23

---

## 调候总则

1. **冬生（亥子丑月）**：水寒金冷，首取火暖局
2. **夏生（巳午未月）**：火炎土燥，首取水润局
3. **春生（寅卯辰月）**：木旺生发，需水火并用
4. **秋生（申酉戌月）**：金旺肃杀，需火制金，水润金

**调候角色**：调候为急，寒暖燥湿先看；但格局决定命局结构主轴，调候辅助修正。实务中先查调候偏枯（紧急修正），再定格局成败（结构主线）；若调候与格局结论冲突，不可用调候压过格局，须在报告中说明二者如何协调。《穷通宝鉴》调候优先于《栏江网》通关扶抑，但均不取代子平格局主轴。

## 调候应用规则

### 1. 优先级

```
1. 格局用神/救应用神 → 主轴
2. 调候用神（寒暖燥湿）→ 修正
3. 通关用神（两行相战）→ 修正
4. 扶抑用神（旺衰平衡）→ 基础
```

调候很重要，但在本 skill 中不单独压过格局主轴；若调候与格局用神冲突，必须写明取舍。

### 2. 极端情况

- **冬生无火**：寒木不生，寒金不暖，难有作为
- **夏生无水**：火炎土燥，金熔木枯，健康受损
- **调候到位**：即使格局一般，也能小富小贵

### 3. 调候与扶抑冲突

- 调候与扶抑冲突时，**调候优先**
- 寒暖适中者，以扶抑为主
- 极端寒热者，调候为急
