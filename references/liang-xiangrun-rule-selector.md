# 梁湘润体系规则选择器

> 用于解决“什么时候套哪条规则”的问题。核心目标：先定判断层级，再下断语；每条断语必须有出处、条件和限制。
> 最后更新：2026-01-22

---

## 一、总流程

梁湘润体系重实务次第。报告和断事按以下顺序：

```
时间校正 → 五行缺一 → 月令格局 → 刑冲合害 → 调候 → 十神星宫 → 天透地藏 → 十二长生根气 → 病药修正(±1级调校) → 大运流年触发 → 应事断语 → 盲派口诀交叉校验
```

不可跳步：

- 时间不准，后面全部降级。
- 月令未定，不谈格局。
- 原局刑冲合害未看，不谈六亲稳定。
- 大运未看，不谈某年成败。
- 流年未触发，不落具体年份。

## 三、梁湘润实务次第

### 1. 五行缺一先看

使用时机：

- 原局某五行完全不见，或明暗皆弱。
- 缺的是财、官、印、食伤之一，且对应现实问题明显。

用法：

- 缺财：钱财、父亲、妻星、现实资源不足或难落地。
- 缺官杀：事业规则、职位、子女星、约束力不足。
- 缺印：母亲、学历、贵人、保护、承接力不足。
- 缺食伤：表达、技术输出、子女生产、制杀出口不足。

限制：

- 五行缺一不是直接吉凶，必须看是否为调候或格局所需。
- 缺的五行在大运流年出现，常是应事点，不一定全吉。

出处：梁湘润五行缺一优先法；调候参《穷通宝鉴》。

### 2. 财官引月令

使用时机：

- 判断配偶、事业、财富层级。
- 判断父辈家境或妻家夫家条件。

用法：

- 财官在月令生旺，且为喜用，层级上调。
- 财官在月令死绝或受冲破，层级下调。
- 财官旺但为忌，先断压力、责任、现实牵制，不直接断富贵。

出处：梁湘润财官引月令法；《子平真诠》月令格局。

### 3. 刑冲合害先看

使用时机：

- 断婚姻、子女、父母、迁动、灾祸风险。
- 原局有双冲、三刑、自刑、六害、合化、合而不化。

用法：

- 冲到日支：婚姻、居住、中年生活动。
- 冲到时柱：子女、晚年、项目末端动。
- 冲到年月：父母、祖上、早年、家境动。
- 合财遇冲：财务变动、破财或资产打开。
- 三刑全见：风险加重，不作死亡绝断，只作风险提示。

出处：《三命通会》刑冲合害；梁湘润流年法则。

### 4. 调候为急

使用时机：

- 寒暖燥湿极端，特别是夏火冬水、燥土寒金。
- 调候与扶抑结论冲突时。

用法：

- 夏生火燥，水为调候；冬生寒湿，火为调候。
- 调候到位可改善格局清浊，但不能单独压过月令格局。
- 调候缺失时，性格、健康、事业舒展度要降级。

出处：《穷通宝鉴》《栏江网》；梁湘润调候法。

### 5. 格局用神分明

使用时机：

- 定格局成败、职业路线、财富官职层次。

用法：

- 官格喜财生印护，忌伤官克官。
- 杀格喜食制杀或印化杀，忌财党杀、杀重身轻。
- 财格喜身旺或食伤生财，忌比劫夺财、财多身弱。
- 食神格喜生财，忌枭印夺食。
- 建禄月劫须财官食伤可用，忌禄多无依。

出处：《子平真诠》格局成败；梁湘润格局用神法。

### 6. 天透地藏

使用时机：

- 判断某十神是否真正有力。
- 判断六亲是否显、能否落现实。

用法：

- 天干透、地支藏且得令得地，力量最大。
- 只透无根，表面有事，落实不足。
- 只藏不透，暗中有事，需大运流年引出。
- 透而被合克冲，事有阻碍或转向。

出处：梁湘润天透地藏法；子平透藏法。

### 7. 根气轻重制

使用时机：

- 判断制化是否有效，例如食神制杀、印化杀、财制印。
- 判断财官妻子子女父母是否有气。

用法：

- 制神有根，被制之神无根，制化有效。
- 被制之神有根，制神无根，制不住，反成压力。
- 双方都有根，看月令、大运、流年哪方得势。
- 双方都无根，多为虚象，须等岁运引动。

出处：梁湘润根气轻重制法；十二长生根气法。

## 四、事项断法选择

### 1. 家境父母

```
年/月宫 → 父母星 → 财印官是否成体系 → 十二长生 → 墓库 → 早年大运
```

断语必须区分：

- 财务议题明显
- 父母辛苦求财
- 小康有底
- 父辈资产较多
- 父母助力有限

不能把财星旺直接断为家里有钱。

### 2. 配偶

```
男命财星/女命官杀 → 日支夫妻宫 → 星的生旺墓绝 → 宫位刑冲合害 → 大运流年婚期
```

断语必须包含：

- 配偶性格
- 配偶能力资源
- 婚姻舒适度
- 婚姻压力来源
- 婚恋应期

### 3. 子女

```
男命官杀/女命食伤 → 时柱子女宫 → 子女星生旺墓绝 → 时柱冲空刑害 → 胎产流年
```

断语必须包含：

- 子女缘厚薄
- 生育难易
- 偏男/偏女主倾向
- 子女性格能力
- 应期年份

### 4. 事业

```
格局 → 官杀/食伤/印星 → 月令旺衰 → 制化是否有效 → 大运是否打开
```

断语必须区分：

- 有职位机会
- 有压力但无平台
- 技能变现
- 管理权责
- 自营/上班/平台路线

### 5. 财富

```
财星 → 日主承载 → 食伤生财 → 财库开合 → 大运流年
```

断语必须区分：

- 流水
- 净利润
- 现金流
- 资产沉淀
- 负债压力

## 五、断语出处格式

每条关键断语至少按以下格式写：

```markdown
依据：月令X格（《子平真诠》）+ X星在X宫生旺/入墓（十二长生）+ 大运X引动X宫（梁湘润流年法则）。
限制：若出生时辰/地点有误，此断语降级；若现实行业承接不足，只应压力不应富贵。
```

禁止写法：

- “财旺所以有钱。”
- “官杀旺所以事业好。”
- “时柱好所以子女好。”
- “有财库所以家里有资产。”

必须写成：

- “财旺且为喜、日主能担、食伤生财、大运助财，才断可得财。”
- “官杀旺且有印化/食制，才断职位权责；无制化则先断压力。”
- “子女星旺且时柱不破，才断子女缘顺；时柱受冲则养育操心。”
- “财库得护且早年运助年月，才断父辈资产；财库被冲或为忌，先断钱财压力。”
