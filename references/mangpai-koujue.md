# 盲派实用口诀

> 盲派命理是中国民间命理师口传心授的实战体系，不依赖格局论，强调"象法"与"宾主"。
> 本文件精选盲派中可与子平体系互补的实用口诀，用于快速交叉校验，不作为格局主轴。
> 最后更新：2026-01-22

---

## ⚠️ 使用规则（硬性限制）

1. **盲派口诀只作旁证和快速交叉校验，不参与格局、用神、大运的主判断。**
2. 盲派断语与子平体系冲突时，以梁湘润子平体系为准，盲派仅标注"盲派视角：XXX"。
3. 盲派的"宾主""功""贼神"等框架与本 skill 体系层级不同，不得混用。
4. 生男生女口诀为概率性经验，必须配合子女星 + 时柱宫位给出，不得单用口诀断性别。

## 一、六亲排行口诀

> 盲派断兄弟姐妹排行有实战价值，但准确性依赖出生时辰精到分钟。

### 基本法则

| 口诀 | 说明 |
|------|------|
| **子午卯酉** | 兄弟多，排行非长即幼 |
| **辰戌丑未** | 兄弟少，常独子或排行中间 |
| **寅申巳亥** | 兄弟一二人，排行偏长 |
| 日柱坐子午卯酉 | 本人非长即幼 |
| 日柱坐辰戌丑未 | 本人多为独子或老幺 |
| 日柱坐寅申巳亥 | 本人多为长子/长女 |

### 时柱排兄弟数（参考）

> 以时支定兄弟数，年支校正（盲派经验口诀，准确性约65-70％）

| 时支 | 兄弟数倾向 |
|------|-----------|
| 子、午、卯、酉 | 3-5人（或为独子/独女） |
| 辰、戌、丑、未 | 1-2人 |
| 寅、申、巳、亥 | 2-3人 |

**限制**：受计划生育、地域、时代影响极大，只作参考，不作定断。

> 必须配合子女星 + 时柱宫位使用。单独用口诀断性别为违规操作。

| 口诀 | 适用条件 | 倾向 |
|------|---------|------|
| **官杀旺而清透，时柱得金水/阳干** | 官杀有根、时柱阳性 | 男孩倾向增强 |

## 三、发财/破财年份标志（盲派应期口诀）

> 以下为盲派总结的流年财象口诀，需与子平财格和大运配合使用。

### 发财标志

| 口诀 | 条件 |
|------|------|
| **财库逢冲** | 辰戌丑未财库被流年冲开，且财为喜用 |
| **食伤生财流年** | 食伤为用，流年透食伤或食伤得地 |
| **财星合日主** | 流年天干（财星）与日主相合 |
| **禄神合财** | 流年禄神合财星 |
| **驿马带财** | 寅申巳亥驿马逢财星流年 |

### 破财标志

| 口诀 | 条件 |
|------|------|
| **比劫夺财** | 流年比肩劫财旺而克财星 |
| **财星被合走** | 财星被流年天干合去（非合日主） |
| **财库被刑破** | 辰戌冲、丑未冲破坏财库 |
| **财星入墓** | 财星临墓库，财路阻塞 |
| **羊刃见财** | 羊刃流年见财星（劫夺之象） |
| **冲财、穿财** | 流年冲原局财星或穿害财星 |

## 四、灾祸信号口诀

| 口诀 | 条件 | 应事类型 |
|------|------|---------|
| **伤官见官** | 原局伤官旺，流年见正官，无印制化 | 官非口舌、职业变动、名誉受损 |
| **枭神夺食** | 偏印旺，流年见食神被夺 | 健康、饮食之灾、失业、子女不顺 |
| **羊刃倒戈** | 羊刃逢冲的流年 | 血光、争斗、手术、意外 |
| **岁运并临** | 大运干支 = 流年干支 | 吉凶加倍（看是否为喜用） |
| **天克地冲** | 流年天干克日主，地支冲日支 | 重大变动或健康风险 |
| **三刑全见** | 寅巳申或丑戌未同现（原局+流年） | 意外、官司、手术（不作死亡断定） |
| **伏吟** | 流年与年/月/日柱相同 | 事有反复、拖延、纠结 |
| **反吟** | 流年冲年/月/日柱 | 变动、搬迁、转业、六亲变动 |

## 五、盲派"宾主"与"功"简要框架

> 盲派的核心方法论。此处仅作简要介绍，供交叉验证时参考。

### 宾主概念

| 概念 | 含义 |
|------|------|
| **主位** | 日柱（日干日支）为我；延伸为我家——比劫、印、食伤 |
| **宾位** | 年月时柱为他人 | 
| **宾位中的"主"** | 财官在日支配偶宫——别人的东西到了我家 |

### "功"的概念

> 盲派所谓"功"，是指八字中的做功机制——用什么方式获取财富、地位。

| 做功方式 | 说明 |
|---------|------|
| **合功** | 日主合财合官——直接获取 |
| **克功** | 通过克的方式获取（食伤生财、食神制杀等） |
| **泄功** | 通过泄秀获取（食伤泄秀成名） |
| **墓功** | 通过财库官库、开库获取（辰戌丑未） |

**盲派判断要点（仅作子平旁证）**：
- 原局做功方式清晰，大运配合 → 事业有成；
- 做功方式混乱，大运不配合 → 事业多波折；
- 宾位财官旺，主位弱 → 看得到得不到；
- 主位旺且有财官 → 能力可落地。
