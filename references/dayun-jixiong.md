# 大运吉凶判断

> 大运十年一运，影响人生运势走向
> 最后更新：2026-04-23

---

## 大运基本规则

### 大运排法
- **阳男阴女顺行**：从月柱顺排
- **阴男阳女逆行**：从月柱逆排
- **起运数**：从生日到最近节气天数÷3
  - 3天 = 1岁
  - 1天 = 4个月
  - 1时辰 = 10天

### 大运重要性
- 大运主宰十年运势
- 大运可补命局之不足
- 大运可破命局之格局
- 好命遇好运，富贵双全
- 好命遇坏运，怀才不遇
- 坏命遇好运，虽成犹败
- 坏命遇坏运，困顿与风险较重

大运是判断人生层次的关键。命局只能说明原始结构，大运决定这个结构在某十年是否被打开。报告中必须先讲完整大运，再讲流年；流年只是触发器，不可越过大运直接断吉凶。

## 大运与命局互动

### 一、用神到位

**吉运判断**：
- 大运走用神五行，运势亨通
- 大运帮扶用神，事业顺遂
- 大运克制忌神，困难解除

**具体表现**：
| 用神类型 | 走用神运表现 |
|---------|------------|
| 财为用神 | 走财运，财运亨通，收入增加 |
| 官为用神 | 走官运，事业有成，升迁有望 |
| 印为用神 | 走印运，学业进步，贵人相助 |
| 食伤为用神 | 走食伤运，才华发挥，创作有成 |
| 比劫为用神 | 走比劫运，合作顺利，朋友相助 |

### 二、忌神到位

**凶运判断**：
- 大运走忌神五行，运势受阻
- 大运克制用神，困难重重
- 大运帮扶忌神，灾祸频发

**具体表现**：
| 忌神类型 | 走忌神运表现 |
|---------|------------|
| 财为忌神 | 赋财运，破财损耗，感情纠葛 |
| 官为忌神 | 赋官运，压力过大，官司是非 |
| 印为忌神 | 赋印运，懒散依赖，思想消极 |
| 食伤为忌神 | 赋食伤运，才华难发挥，泄气太多 |
| 比劫为忌神 | 赋比劫运，竞争激烈，被人算计 |

### 三、用神忌神判断原则

1. **身弱用印比**：走印比运为吉，走财官食伤运为凶
2. **身旺用财官食伤**：走财官食伤运为吉，走印比运为凶
3. **从格用旺神**：走旺神运为吉，走克泄运为凶
4. **调候用神**：寒需火，热需水，燥需水，湿需火

## 岁运并临

### 基本概念
- **岁运并临**：大运与流年干支相同或相近
- **岁运相冲**：大运与流年干支相冲
- **岁运相合**：大运与流年干支相合

### 吉凶判断

**岁运并临（吉）**：
- 用神岁运并临，吉上加吉
- 大运流年同为用神，好运加倍
- 如：身弱用印，大运流年同为印运

**岁运并临（凶）**：
- 忌神岁运并临，凶上加凶
- 大运流年同为忌神，灾祸加倍
- 如：身弱忌财，大运流年同为财运

**岁运相冲**：
- 冲克用神，运势动荡
- 冲克忌神，反为吉兆
- 如：财为用神，大运流年冲财，破财

**岁运相合**：
- 合住用神，好运受阻
- 合住忌神，凶运减轻
- 合化成功，看化神吉凶

### 经典论述
> "岁运并临，吉凶加倍。用神并临吉，忌神并临凶。"

## 大运重地支原则

### 基本原则
- **大运重地支**：地支代表大运的主要力量
- **流年重天干**：天干代表流年的主要力量

### 判断方法

**大运分析（重地支）**：
1. 大运地支为用神根基，十年运势稳
2. 大运地支为忌神根基，十年运势难
3. 大运地支冲克命局根基，动荡十年
4. 大运地支合会命局根基，稳定十年

**流年分析（重天干）**：
1. 流年天干为用神，当年吉
2. 流年天干为忌神，当年凶
3. 流年天干克大运天干，运势变
4. 流年地支影响大运地支根基

### 实例说明
- 大运甲子，子为用神根基，十年运势平稳向好
- 流年甲午，甲为用神天干，当年运势好，但午冲子根基有动荡

## 大运各阶段判断

### 起运前（童限）
- 用小运判断（见小运章节）
- 小运与流年同参

### 第一步大运
- 从月柱顺/逆排第一步
- 影响童年到青年过渡
- 关键时期，影响人生基础

### 中年大运
- 人生黄金时期
- 大运好坏直接影响事业财运
- 婚姻家庭在此阶段成型

### 晚年大运
- 影响健康寿元
- 子女运势在此阶段体现
- 大运走印运，晚年安稳

## 大运吉凶判断流程

### 第一步：判断命局用神忌神
1. 先确认排盘时间：夏令时、真太阳时、晚子时换日
2. 确定格局类型、成败与救应
3. 判断日主强弱、调候、通关
4. 找出格局用神、调候用神、扶抑用神的层级

### 第二步：分析大运干支
1. 大运天干是什么五行
2. 大运地支是什么五行
3. 与用神忌神的关系
4. 与六亲宫位、财库、印星、子女星的关系

### 第三步：判断吉凶
1. 大运走用神运，十年吉
2. 大运走忌神运，十年凶
3. 大运半吉半凶，看流年配合
4. 大运只定阶段环境，不单独落定年份
5. 连续两步或三步喜用大运，可明显抬高命局层次；连续忌神破格大运，则即使命局好也容易反复。

### 第四步：结合流年
1. 流年引动大运吉凶
2. 流年可补救大运不足
3. 岁运并临特别注意
4. 买房买车、婚育、灾祸、升迁、破财等具体事项，必须由流年触发后再断年份

### 第五步：重点应事分类

| 应事 | 大运看什么 | 流年触发 |
|------|------------|----------|
| 子女/生育 | 食伤、官杀、时柱、子女宫是否得运 | 合冲时柱、子女星透出、胎产信号 |
| 家境改善 | 年月柱、父母宫、财印是否得力 | 财印到位、合动年月、库被打开 |
| 买房 | 印星、土库、财星承载力 | 辰戌丑未、财印、合冲库、搬迁动象 |
| 买车 | 财星、驿马、金舆、动象 | 驿马被冲合、财星透、出行交通信号 |
| 事业升迁 | 官杀、印星、格局清浊 | 官印到位、官杀受制化、工作宫被引动 |
| 破财灾祸 | 七杀、羊刃、伤官、忌神成势 | 岁运并临、刑冲破害、用神受伤 |

### 第六步：大运报告格式

每一步大运必须按以下格式输出：

| 项目 | 要求 |
|------|------|
| 大运干支 | 写清天干十神、地支十神 |
| 年龄年份 | 写年龄段和公历年份 |
| 与原局作用 | 写冲、合、刑、害、会、伏吟、反吟 |
| 十年主题 | 事业/财运/婚姻/子女/家宅/健康/迁移 |
| 吉凶等级 | 吉、平、凶必须给依据 |
| 可应事项 | 这十年容易发生的现实事件 |
| 流年触发 | 列出本步大运中最强的2-4个年份 |

## 大运断语汇总

### 吉运断语
- **走财运**：财运亨通，收入增加，利于求财
- **走官运**：事业有成，升迁有望，贵人相助
- **走印运**：学业进步，贵人相助，安稳平顺
- **走食伤运**：才华发挥，创作有成，子女顺利
- **走比劫运**：合作顺利，朋友相助，竞争得胜

### 凶运断语
- **走财运（忌神）**：破财损耗，感情纠葛，压力增加
- **走官运（忌神）**：压力过大，官司是非，职场困难
- **走印运（忌神）**：懒散依赖，思想消极，贵人少助
- **走食伤运（忌神）**：泄气太多，才华难发挥，子女不顺
- **走比劫运（忌神）**：竞争激烈，被人算计，合作失败

### 特殊情况断语
- **用神大运遇忌神流年**：好中有坏，需谨慎
- **忌神大运遇用神流年**：坏中有好，有转机
- **岁运并临用神**：大吉大利
- **岁运并临忌神**：风险叠加，需提前预防

## 大运判断注意事项

1. **大运好坏非绝对**：命局为体，大运为用
2. **流年可改变大运效果**：好运遇坏流年，好事难成
3. **格局高低影响大运效果**：格局高者，坏运也有限
4. **用神有力者，大运影响大**：用神无力者，大运效果小
5. **从格特殊**：从格走逆运，灾难深重

---

**天干地支权重说明**：传统有「前五年天干、后五年地支」之说，梁湘润体系亦有此口径。本体系实务中判断十年大运底色时，以地支为运势基调、天干为事象表现；逐年流年断事时则天干地支均须同参，不可只看天干或只重地支。
