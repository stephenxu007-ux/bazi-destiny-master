# 六亲断语体系

> 所有断语必须有经典依据，不可凭空编造
> 基于梁湘润《子平八字》《子平教材》、《三命通会》、《滴天髓》、《穷通宝鉴》
> 最后更新：2026-05-21

---

## 核心原则

**断语 = 十神 + 宫位 + 旺衰 + 刑冲合化 + 大运流年**

六亲是本 skill 的主要断事入口。先断家庭结构与亲缘，再延伸到家境、资产、婚育、事业财运和灾祸风险；性格只作辅助。

每一条断语必须包含：
1. 依据什么（哪个十神在哪个位置、什么状态）
2. 推导出什么结论
3. 出自哪本经典/哪条法则

### 六亲优先级

1. **六亲星**：父看偏财、母看正印，男命配偶看财、女命配偶看官杀，子女以食伤/官杀和时柱同参。
2. **六亲宫**：年柱祖上父母，月柱父母兄弟，日支配偶，时柱子女。
3. **岁运触发**：六亲星或六亲宫被大运流年合冲刑害，才落具体年份。
4. **家境资产**：看年月柱、财印、库气、财库印库、父母宫是否得力。
5. **灾祸风险**：看对应六亲星受克、宫位受冲、岁运并临、三刑全见、用神受伤。

### 家境资产判别规则

家境不能只凭“财星旺、财星透、财库在年柱”直接断富。必须区分三层：

| 层级 | 可断内容 | 条件 |
|------|----------|------|
| 财务信息明显 | 家里重钱、父辈现实、钱财压力或资产议题明显 | 年月见财、财库、财星透藏，但未必为用或未必得护 |
| 家境不差/有底子 | 有房产、经营、稳定收入或可见资源 | 年月财印官配合，财为喜用或有印比承接，父母宫不严重受冲破 |
| 家底厚/资产多 | 父辈事业、厂房、公司、较多房产/资本积累 | 年月财官印成体系，财库得护，财为用且大运早年助财官印，少见比劫夺财/冲破父母宫 |

修正规则：
- 财星旺而为忌、财生杀、财被比劫夺、财库被冲，常体现为“钱财压力、房贷债务、父辈辛苦、家里重现实”，不能直接断家底厚。
- 年柱有财或财库，只能先断“祖上/父辈有财务议题、资产意识、土地房产或经营信息”，是否有钱要看年月宫组合和喜忌。
- 父亲有赚钱能力、父亲辛苦打工、父辈有资产，是三个不同结论。必须分别写，不得混成“父亲有能所以家境好”。
- 若用户反馈家境事实，回查规则时优先修正“财星含义层级”，不要为了圆断语把所有财星都解释成资产。

### 六亲细断格式

每个六亲必须按以下字段输出，不得只给一句泛断：

| 字段 | 说明 |
|------|------|
| 性格脾气 | 急/慢、强势/温和、固执/变通、外向/内敛、情绪稳定度 |
| 能力资源 | 赚钱能力、学历能力、管理能力、人脉资源、家庭照顾能力 |
| 与命主关系 | 亲近/疏离、助力/压力、沟通顺逆、是否容易有代沟 |
| 现实表现 | 家境、职业倾向、家庭权力结构、财务习惯 |
| 应期年份 | 哪些大运流年引动该六亲星或宫位 |

示例：父亲不能只写“父亲能力一般”，要说明“偏财藏于月令但空亡/受冲，主有赚钱机会但稳定度不足；某运某年引动偏财或月柱，父亲/家境事项明显”。

配偶不能只写“务实”。必须说明：
- 性格脾气：财星阴阳、日支藏干、夫妻宫刑冲合害。
- 能力资源：财星旺衰、有根无根、是否透干、是否为用。
- 相处矛盾：日支被冲害、自刑、财星被比劫夺、财坏印等。
- 婚姻年份：财星透出、合动日支、冲动夫妻宫、桃花与大运配合。
- 若命局官杀旺、财星坐夫妻宫或夫妻宫受官杀/刑害牵动，配偶常见强势、能管事、规则感强、能力不弱；若财星为用或有根，配偶实际能力和持家能力要上调。

子女不能只写“有子女缘”。必须说明：
- 子女性格：时柱十神、时支五行、子女星阴阳。
- 子女能力：食伤/官杀是否清、有根、有印化。
- 亲子关系：时柱与日支关系、时柱被冲合刑害。
- 生育年份：子女星透出、时柱被合动、食伤官杀得地的大运流年。

### 生儿生女与子女缘

生儿生女论倾向，不作医学或绝对断言；但报告必须给出明确主判断，不能用“难以判断”逃避。若信息矛盾，给“主倾向 + 反证 + 置信度”。

固定输出字段：

| 字段 | 必填要求 |
|------|----------|
| 子女星强弱 | 男命官杀，女命食伤；列明透干、藏支、有根、得令、是否为喜用 |
| 时柱子女宫 | 时干时支十神、喜忌、空亡、刑冲合害、与日支关系 |
| 子女缘厚薄 | 厚/中/薄，说明是否迟、少、操心、远离、得力 |
| 生育难易 | 顺/中/难，说明是否容易怀孕、生育波折、养育操心 |
| 性别倾向 | 偏男/偏女/先男后女/先女后男，必须给主结论和置信度 |
| 子女性格能力 | 由子女星五行、时柱十神和宫位推断 |
| 应期年份 | 列大运与流年，尤其子女星透出、时柱被合冲、胎产信号年份 |

基础法则：

- 女命以食伤为子女主星，男命以官杀为子女主星，均需兼看时柱。食伤同时代表生养、生产、教育和对子女投入，男命也要辅助看食伤是否能引动子女事项。
- 时柱为喜、子女星有根且不受严重冲克，多主子女缘较顺；时柱为忌、空亡、被冲刑害、子女星入墓或被重克，多主子女缘迟、少、操心、生产过程需注意。
- 流年合动时柱、子女星透出、食伤官杀得力，是怀孕生育的常见触发。大运只定十年底色，流年才落具体胎产年份。
- 生儿生女不得按单一“时柱阴阳”下结论，必须综合子女星阴阳、子女星五行、时柱阴阳、强弱清浊、刑冲合害和生育流年。

性别倾向规则：

| 条件 | 倾向 |
|------|------|
| 男命官杀旺而清，官杀透干有根，时柱得金水/阳动配合 | 男孩倾向增强 |
| 男命官杀弱、藏而不透，食伤旺克官杀，时柱阴柔或子女星受制 | 女孩倾向或得子较迟 |
| 女命食伤旺而清，伤官/阳火阳木先透，时柱阳性、流年阳动 | 男孩倾向增强 |
| 女命食神/阴性食伤为主，时柱阴性，流年阴柔引动 | 女孩倾向增强 |
| 子女星混杂、时柱受冲、男女信号并见 | 先按强者断主倾向，再写反证和置信度中/低 |
| 子女星落空亡、入墓、被印重克、时柱重冲 | 子女缘薄/迟/生育难度上升，性别倾向降级 |

常用断语参考：

- “食伤为子息，食伤得地则子息有气；受印制太过则生产生养不顺。”来源：子平食伤子息法、《渊海子平》子息类断。
- “男命官杀为子女，官杀有根而时柱不伤，子女有力；官杀被食伤重制或空亡，子息迟薄。”来源：子平六亲法、《三命通会》子息法。
- “时为子息宫，喜生旺不喜刑冲空破；时柱逢冲，子女远、迟、变动或养育操心。”来源：《三命通会》时柱子息宫法。
- “子息以星宫同参，星旺宫稳为顺，星弱宫破为难；岁运引动方可落胎产年份。”来源：梁湘润流年法则。

反馈校正规则：男命若官杀成势、子女星旺，且实际流年引动阳性/杀星/木火阳动，也可能多男孩。若用户反馈已有子女，应回查对应生育流年的官杀、食伤、时柱触发，不再坚持原先性别倾向。

### 反馈校正规则

当用户提供已发生事实（如两个儿子、配偶强势、某年升职）：

1. 不要辩解原断语，先承认原判断不充分。
2. 找回原局中可解释该事实的结构，例如官杀旺、时柱强、财星有根、夫妻宫受害。
3. 回查发生年份对应的大运流年触发。
4. 更新后续同类断法，避免重复同一单点错误。
