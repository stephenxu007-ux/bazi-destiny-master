# 原局大运流年三方联动规则

> 命局是车，大运是路，流年是天气。三者联动才是真断法。
> 基于梁湘润《子平八字》《流年法则》及《三命通会》
> 最后更新：2026-04-23

---

## 核心原则

**命局** = 先天体质（静态）
**大运** = 十年环境（中期动态）
**流年** = 当年触发（短期动态）

判断好坏时，大运权重大于单一年份。命局一般但连续三十年走喜用、成格、调候到位的大运，人生层次可以明显抬高；命局好但长期走破格、忌神、冲用神的大运，也会表现为怀才不遇、反复折腾。

### 三方作用优先级

```
1. 流年天干 → 当年表象（上半年应事）
2. 流年地支 → 当年实质（下半年应事，太岁力量最大）
3. 大运天干 → 前5年主导
4. 大运地支 → 后5年主导，对原局产生持续影响
5. 原局 → 承受大运流年作用的基础
```

### 联动断法公式

```
原局四柱
→ 定格局、用神、六亲宫位、原局刑冲合害
→ 大运干支进入原局，定十年底色和主线
→ 流年干支进入“大运+原局”，触发具体事件
→ 找出所有刑冲合会害与伏吟反吟
→ 判断化神是否成立（月令、透干、根气）
→ 确定哪个十神、哪个宫位、哪类现实事项被引动
→ 给出年份断语
```

### 大运先行评分

每一步大运必须先评估十年底色：

| 维度 | 判断问题 |
|------|----------|
| 用神 | 大运干支是否为格局用神、调候用神、扶抑喜神 |
| 忌神 | 大运是否加重忌神、破格、冲克用神 |
| 宫位 | 大运地支是否冲合刑害年月日时某宫 |
| 十神 | 大运透出的十神主导哪类人事：财、官、印、食伤、比劫 |
| 承载 | 日主是否能承受财官，是否有印比护身或食伤泄秀 |
| 连续性 | 前后两步大运是否连续走喜/忌，形成10年、20年、30年趋势 |

大运评价必须写成“十年主线”，例如：
- 财官运：事业责任、婚姻、资产、制度压力增强。
- 印比运：学习资质、贵人、稳定、健康恢复增强。
- 食伤运：表达、技术、销售、创业、子女事项增强。
- 忌神运：机会也可能有，但代价、压力、反复更大。

### 应事落年原则

具体年份不能只看“流年是用神/忌神”，必须满足至少两类触发：

1. **十神触发**：财、官、印、食伤、比劫等对应事项出现。
2. **宫位触发**：年/月/日/时支被冲合刑害，或对应宫位被大运流年引动。
3. **结构触发**：格局成败、用神受助/受伤、财库印库打开、三合三会成势。
4. **象意触发**：驿马、金舆、桃花、羊刃、天乙等神煞作为旁证。

断买房、买车、婚育、灾祸、升迁、破财等年份时，至少写出“十神 + 宫位/结构”的两条依据。

### 年份断事优先级

1. **大运定主题**：这一十年主要是事业、财、婚姻、子女、家宅、健康，还是迁移变化。
2. **流年找触发**：流年冲合刑害原局或大运，才落具体年份。
3. **宫位定对象**：冲年看长辈家族，冲月看父母兄弟事业环境，冲日看自己/配偶/家宅，冲时看子女/下属/晚辈/项目末端。
4. **十神定事项**：财为钱财妻缘资产，官杀为事业规则压力子女，印为母亲贵人房产文书，食伤为表达技术子女，比劫为兄弟朋友竞争。
5. **现实年龄校验**：1-16岁不强断事业投资，20-35岁重点看学业转业婚恋买车，30-50岁重点看事业家庭资产子女，50岁后看资产收束、健康、子女。

### 全生命周期回看

报告必须区分：

- **已发生候选年份**：出生年至当前年份，尤其20岁以后，用于让用户核验准确率。
- **未来候选年份**：当前年份以后，用于提示趋势。

买房买车、婚姻子女、升迁破财等事项，先扫完整流年表，再汇总，不可只在未来年份里找。

## 一、大运与原局的联动

### 1. 大运天干透入原局

**规则**：大运天干 = 原局某十神透干，引动对应事项

| 大运透十神 | 引动事项 | 依据 |
|-----------|---------|------|
| 比肩/劫财 | 朋友往来、竞争、破财、合作 | 梁湘润流年法则 |
| 食神/伤官 | 才华发挥、口舌是非、子女事 | 《三命通会》 |
| 正财/偏财 | 财运、感情、父亲事 | 《子平真诠》 |
| 正官/七杀 | 事业变动、压力、官非、女感情 | 《滴天髓》 |
| 正印/偏印 | 学业、长辈、房产、贵人 | 《三命通会》 |

### 2. 大运地支与原局地支的作用

#### 大运地支冲原局地支（最剧烈）

| 组合 | 冲的宫位 | 应事 |
|------|---------|------|
| 大运冲年支 | 祖上/父母宫 | 长辈变动、搬家、祖业事 |
| 大运冲月支 | 父母/兄弟宫 | 父母事、工作变动、环境变 |
| 大运冲日支 | 夫妻宫 | 婚姻感情变动、配偶事 |
| 大运冲时支 | 子女宫 | 子女事、投资、晚年规划 |

**⚠️ 冲的规则**：
- 原局地支被冲 → 该宫位对应人事发生变动
- 原局用神被冲 → 不利
- 原局忌神被冲 → 反而有利（冲去忌神）
- 冲中带合 → 先冲后合，事有转机

#### 大运地支合原局地支

| 合的类型 | 规则 | 应事 |
|---------|------|------|
| 大运六合原局 | 合化成功 → 化神十神主事 | 人事和好、合作 |
| 大运三合原局 | 凑成三合局 → 合化五行旺 | 该五行相关事项大涨 |
| 大运三会原局 | 凑成三会局 → 方位五行旺 | 方位、行业相关事 |

**合化成功条件**（必须同时满足）：
1. 天干透出化神五行
2. 大运地支或流年地支支持化神
3. 原局无冲克化神之字

**⚠️ 重要**：大运与原局合而不化 = 合绊，双方都被牵制

#### 大运地支刑原局地支

| 刑的类型 | 应事 |
|---------|------|
| 无恩之刑（寅巳申） | 恩将仇报、口舌是非、官非 |
| 恃势之刑（丑未戌） | 权势斗争、内部矛盾、肠胃病 |
| 无礼之刑（子卯） | 失礼得罪人、感情纠纷 |
| 自刑 | 自我纠结、抑郁、自找麻烦 |

#### 大运地支害原局地支

| 害的组合 | 应事 |
|---------|------|
| 子未害 | 亲情不和、脾胃病 |
| 丑午害 | 是非口舌、心脏问题 |
| 寅巳害 | 人际不和、肝胆病 |
| 卯辰害 | 兄弟不和、肠胃病 |
| 申亥害 | 奔波不顺、肾脏问题 |
| 酉戌害 | 口舌是非、肺部问题 |

## 二、流年与命局的联动（每年必看）

### 1. 流年天干的作用

**流年天干**是当年最表面的现象：

| 流年天干十神 | 当年表象 | 依据 |
|-------------|---------|------|
| 比肩 | 自我意识增强、竞争、朋友多 | 梁湘润 |
| 劫财 | 破财风险、竞争加剧、冲动消费 | 流年法则一 |
| 食神 | 才华展现、享受、子女缘 | 《三命通会》 |
| 伤官 | 创新变动、口舌是非、叛逆 | 《子平真诠》 |
| 正财 | 稳定收入、感情发展、务实 | 《穷通宝鉴》 |
| 偏财 | 意外之财、投机、父亲事 | 《子平真诠》 |
| 正官 | 事业提升、贵人、女感情 | 《滴天髓》 |
| 七杀 | 压力增大、小人、变动 | 《滴天髓》 |
| 正印 | 学业进步、长辈帮助、贵人 | 《三命通会》 |
| 偏印 | 孤独思考、偏门才华、继母事 | 《三命通会》 |

### 2. 流年地支的作用（太岁）

**流年地支（太岁）是一年的主人**，力量最大：

- 太岁冲原局 → 变动
- 太岁合原局 → 和好/牵绊
- 太岁刑原局 → 是非/疾病
- 太岁是原局用神 → 吉利
- 太岁是原局忌神 → 凶险

### 3. 流年与原局的刑冲合化（每年必须特别标注）

#### 流年冲原局（反吟）

| 流年冲 | 宫位 | 应事 | 吉凶判断 |
|--------|------|------|---------|
| 冲年支 | 祖上/父母 | 长辈变动、搬家 | 看用忌神 |
| 冲月支 | 父母/兄弟/事业 | 工作变动、环境变 | 看用忌神 |
| 冲日支 | 夫妻宫 | 婚姻感情变动 | 看用忌神 |
| 冲时支 | 子女/投资 | 子女事、投资变动 | 看用忌神 |

**反吟（冲）**的断法：
- 流年地支冲原局某支 → 该宫位对应人事发生重大变动
- 用神被冲 → 凶
- 忌神被冲 → 吉（冲去忌神为喜）

#### 流年合原局

| 流年合 | 应事 | 吉凶判断 |
|--------|------|---------|
| 合年支 | 长辈缘、祖业事 | 看合化五行 |
| 合月支 | 合作、工作环境好 | 看合化五行 |
| 合日支 | 感情和好、婚姻缘 | 看合化五行 |
| 合时支 | 子女缘、合作投资 | 看合化五行 |

**合**的断法：
- 流年地支合原局某支 → 该宫位对应人事有和好/合作/牵绊
- 合化成功 → 化神五行相关事项增强
- 合而不化 → 合绊，双方被牵制（好事被拖、坏事也被拖）

#### 流年与原局三合/三会

当流年地支 + 原局两个地支 = 三合局/三会局：

| 三合局 | 五行 | 引动十神 | 应事 |
|--------|------|---------|------|
| 申子辰 | 水 | 看水的十神 | 该十神事项大涨 |
| 亥卯未 | 木 | 看木的十神 | 该十神事项大涨 |
| 寅午戌 | 火 | 看火的十神 | 该十神事项大涨 |
| 巳酉丑 | 金 | 看金的十神 | 该十神事项大涨 |

**⚠️ 重要**：三合局成立时，该五行力量急剧增强，对应十神的事项成为当年重点。

#### 流年与原局三刑

| 三刑 | 流年参与方式 | 应事 |
|------|------------|------|
| 寅巳申 | 流年带其中一个，原局有另两个 | 是非官非、车祸、手术 |
| 丑未戌 | 流年带其中一个，原局有另两个 | 内部矛盾、肠胃病、破财 |
| 子卯 | 流年带子或卯，原局有另一个 | 感情纠纷、失礼得罪 |

#### 流年与原局自刑

| 自刑 | 应事 |
|------|------|
| 辰辰 | 自我纠结、肠胃问题 |
| 午午 | 心火旺、情绪问题 |
| 酉酉 | 肺部问题、金属伤 |
| 亥亥 | 肾脏问题、奔波 |

## 三、大运+流年+原局 三方联动（最完整的断法）

### 1. 岁运并临（大运=流年干支）

**岁运并临 = 大运干支和流年干支完全相同**
- 力量加倍
- 吉者更吉，凶者更凶
- **依据**：《三命通会》"岁运并临，不死自己死他人"
- 用神并临多主好事集中；忌神并临或冲克用神，只能断风险升高，不可直接断生死。

### 2. 大运冲 + 流年再冲（双重冲击）

当大运冲了原局某支，流年又冲同一支：
- 该宫位人事剧烈变动
- 可能是灾，也可能是大转机
- 看用忌神定吉凶

### 3. 大运合 + 流年冲（合处逢冲）

当大运与原局某支相合，流年来冲：
- 合被冲破 → 好事被破坏
- **依据**：梁湘润"合处逢冲，事多反复"

### 4. 大运冲 + 流年合（冲处逢合）

当大运冲原局某支，流年来合：
- 冲被合解 → 坏事有转机
- **依据**：梁湘润"冲处逢合，事有转机"

### 5. 大运引动 + 流年触发

最典型的联动模式：
```
大运地支与原局某支相合/冲/刑 → 引动（埋下伏笔）
流年地支再来冲/合 → 触发（应事发生）
```

**举例**：
- 大运合日支（引动婚姻宫） → 流年冲日支（触发婚姻变动）
- 大运冲月支（引动事业宫） → 流年合月支（触发工作变动落实）

### 6. 流年天干 + 大运地支组合

| 流年天干 | 大运地支 | 组合意义 |
|---------|---------|---------|
| 流年天干克大运地支 | 天干胜 | 表面压制实质 |
| 流年天干生大运地支 | 相生 | 顺势而为 |
| 大运地支生流年天干 | 地支生天干 | 环境助力 |
| 大运地支克流年天干 | 地支胜 | 环境制约表象 |

## 五、六亲引动速查表

当某十神被引动（流年/大运出现），对应六亲事项：

| 十神 | 六亲 | 宫位 | 应事领域 |
|------|------|------|---------|
| 比肩 | 兄弟朋友 | 月柱 | 竞争、合作、朋友事 |
| 劫财 | 兄弟姐妹 | 月柱 | 破财、争夺、竞争 |
| 食神 | 子女（女） | 时柱 | 子女、才华、享受 |
| 伤官 | 子女（男） | 时柱 | 子女、创意、口舌 |
| 正财 | 妻子（男） | 日支 | 妻子、收入、父亲 |
| 偏财 | 父亲 | 年柱 | 父亲、偏财、情人 |
| 正官 | 丈夫（女） | 日支 | 丈夫、事业、名声 |
| 七杀 | 情人（女） | 日支 | 情人、压力、权力 |
| 正印 | 母亲 | 年柱 | 母亲、学业、贵人 |
| 偏印 | 继母/长辈 | 年柱 | 继母、孤独、偏才 |

**宫位叠加法则**：
- 十神 + 宫位 = 精确定位
- 例如：偏财在年柱 → 父亲事
- 例如：正官在日支 → 丈夫/事业事

## 六、梁湘润流年断事口诀

1. **"太岁头上坐，动象明显"** — 流年与原局天克地冲，容易有重大变动或风险
2. **"岁运并临，吉凶加倍"** — 大运流年相同，力量翻倍
3. **"合处逢冲，事多反复"** — 大运合被流年冲，好事被破坏
4. **"冲处逢合，事有转机"** — 大运冲被流年合，坏事有救
5. **"三合局成，一事大兴"** — 三合局成立，该五行相关事项大兴
6. **"三刑全见，风险升高"** — 三刑凑齐，灾祸风险升高，需看用忌与宫位
7. **"用神逢冲，好事成空"** — 用神被流年冲，好事落空
8. **"忌神逢冲，反为吉利"** — 忌神被冲去，反而吉利
9. **"伏吟之年，停滞不前"** — 流年与原局相同，事多拖延
10. **"反吟之年，变动不定"** — 流年冲原局，变动多

## 七、刑冲合化优先级

当一年同时出现多种作用时，按以下优先级判断：

```
1. 天克地冲（最凶） — 流年天干克原局天干，流年地支冲原局地支
2. 三合局成立 — 力量最大，主导当年五行
3. 三刑全见 — 灾祸信号
4. 岁运并临 — 吉凶加倍
5. 六合 — 和好/牵绊
6. 六冲 — 变动
7. 六害 — 小人/不和
8. 自刑 — 自我问题
```
