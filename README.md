Bazi Destiny Master
八字命理分析 skill，核心目标是把传统子平八字断法整理成可审计、可复用、可持续校验的 AI 工作流。

本项目不限定 Codex 使用。只要你的 AI 工具支持读取 skill / prompt / 本地知识库，例如 Codex、OpenClaw、Hermes Agent 或其他 agent，都可以调用本项目的 SKILL.md 与 references/。 项目拷贝地址：git clone https://github.com/stephenxu007-ux/bazi-destiny-master.git

项目定位
本项目以梁湘润子平八字体系为主轴，结合《子平真诠》《滴天髓》《三命通会》《穷通宝鉴》《神峰通考》等规则，重点处理：

排盘校验：夏令时、真太阳时、晚子时换日、起运顺逆。
格局判断：月令取格、成格破格、用神救应、病药修正。
六亲断事：父母、配偶、子女、生育难易、生男生女倾向。
家境资产：财星、财库、年月宫、十二长生、大运承接分层判断。
大运流年：20-60 岁逐年吉凶、刑冲合害、应事年份。
交叉验证：盲派口诀只作旁证，不能推翻子平主断。

使用方法
1. 放置 skill
把本目录放到你的 agent 可读取的 skills 目录中即可。不同工具目录不同，示例：

~/.codex/skills/bazi-destiny-master
~/.openclaw/skills/bazi-destiny-master
Hermes agent skills 目录/bazi-destiny-master
如果你的工具不支持自动发现 skill，也可以直接让 AI 先读取：

bazi-destiny-master/SKILL.md
再按 references/bazi-sop.md 的流程生成报告。

2. 输入格式
只需要输入公历生日、性别、出生城市即可。建议格式：

1988年9月7日 19:15，男命，杭州出生。请按八字 skill 出一份完整报告。
或：

2017年7月29日 下午1点15，男命，杭州出生。看格局、性格、父母家境、子女、事业财运和大运流年。
3. 时间说明
默认按公历生日排盘。
1986-1991 年大陆夏令时出生者，需要特别注意先减 1 小时。
晚上 23:00-23:59 出生，本体系按晚子时换日处理。
本人主要以杭州命例验证。杭州出生者真太阳时与北京时间差异较小，一般无需特别校准；其他地区请自行复核真太阳时、经纬度和临界时辰。
关键原则
先核准时间，再谈命理。
先看原局结构，再看大运铺路，最后以流年触发应事。
断语必须有依据、出处、限制和反证。
不得单因单断：财旺不等于一定有钱，官旺不等于一定有职位，时柱好不等于子女一定顺。
交叉验证只调整置信度，不反客为主。
